# Repositório Advocondo

Este repositório contém a documentação do projeto **Advocondo**, um sistema de gestão de contratos voltado para escritórios de advocacia.

A documentação contempla os principais artefatos desenvolvidos ao longo do projeto, incluindo:

- Rastreabilidade;
- Histórias de usuário;
- Prototipação;
- Validação do sistema;
- Documentação da estrutura e do comportamento do sistema.

## Introdução

Aqui estão organizados os principais artefatos utilizados na estruturação do sistema **Advocondo**.

Os documentos foram elaborados com o objetivo de representar de forma clara a **estrutura, o comportamento e as interações do sistema**, servindo tanto como apoio ao desenvolvimento quanto como material de estudo para a compreensão dos conceitos de Engenharia de Software aplicados a um projeto real.
